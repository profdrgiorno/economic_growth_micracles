## 📌 Main Contribution

This repository contains the complete simulation engine and mathematical model for the research paper *Economic Growth: Endogenous Planner and the Fast Period Increasing Returns 'Miracles'*.

The model establishes that **institutional reforms fundamentally re-parameterize the social planner's objective function and constraint set**, lifting variance caps $\bar{X}(I)$ and triggering saddle-node bifurcations in the net drift operator $\mu(X, I)$.
